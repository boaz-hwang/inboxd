# Granite 답장 모델 사전 평가

작성일: 2026-10-06

상태: **추론 및 위임 의미 판정 완료. Granite는 운영 모델로 활성화하지 않았다.** Kanana는 이번 평가 범위에서 제외한다.

## 목적과 범위

기존에 관측한 합성 회귀 사례 24건에서 Granite 4.2-3B의 답장 품질과 추론 자원 사용을 사전 평가한다. 따라서 이 사례들은 새로운 독립 holdout이 아니다. 요청별 입력은 운영 worker의 `compile_prompt`와 `build_generation_input`이 만든 생산 프롬프트를 사용한다. 이는 추론 비교이며, 개인화 학습이나 실제 대화에서의 성능을 입증하지 않는다. 합성 사례 결과를 실제 사용자 대화로 일반화하지 않는다.

평가에는 기존 기준 모델과 Granite를 같은 24건·프롬프트·출력 예산으로 비교한다. 기본 비교는 temperature 0이며, Granite 공식 권장 설정인 temperature 1.0 / top-p 0.95 실행은 별도 조건으로 기록한다. 샘플링 조건은 결과 변동성이 있으므로 temperature 0 결과와 한 점수로 합치지 않는다.

## Granite 입력·생성 호환 조건

운영 프롬프트는 `enable_thinking=False`로 렌더링한다. Granite 공식 예시대로 렌더링한 문자열은 `tokenizer.encode(prompt, add_special_tokens=False)`로 미리 토큰화하고, 토큰 ID를 `generate()`에 전달한다. 공식 모델 카드는 문자열을 그대로 `generate()`에 넘기면 기본 special-token 인코딩으로 spurious BOS가 추가되어 thinking/template 동작에 영향을 줄 수 있다고 안내한다. 최대 생성 길이는 192토큰이다.

설치된 mlx-lm 0.31.3에는 Granite 모델 구현 모듈이 있다. 모델 카드는 Apache-2.0 라이선스를 표시하고 Granite 4.2 MLX 양자화 모델에 temperature 1.0, top-p 0.95를 권장한다. 모델 저장소 크기나 카드의 unified-memory 권장치만으로 실행 중 최대 메모리를 추정하지 않는다. [공식 Granite 모델 카드](https://huggingface.co/ibm-granite/granite-4.2-3b-q4-mlx)

검토는 위임된 단일 에이전트 판정이며 통계적 우위 검정이나 운영 승인 기준이 아니다. 표의 모두 통과·명확한 실패·불확실만은 24건을 나눈 판정이다. Granite greedy는 Qwen보다 명확한 실패 수가 적었지만 전체 통과가 적고 불확실만 판정된 사례가 많았으며 유용성·말투 점수도 낮았다. 권장 샘플링은 명확한 실패 16건으로 가장 낮은 결과를 보였다. 예를 들어 사용자가 강의 녹음을 유료 자료에 쓰지 말라고 거절한 합성 사례에서 Granite 권장 샘플링은 사용에 동의하는 답을 생성했다. 이는 동의 범위를 뒤집은 실패다.

표의 메모리 단위는 GB=10⁹ bytes다. 각 모델 설정은 별도 프로세스이며 swap은 시작·종료 표본에서 변하지 않았다. Granite safetensors 파일은 2,059,005,430 bytes이고 패킹 형식에서 복원한 파라미터 수는 3,659,737,600이다. MLX peak와 RSS는 중첩된 별도 측정치이므로 더하지 않는다. RSS high-water는 워밍업과 앞선 사례를 포함한 프로세스 누적 최댓값이다.

별도 스트레스 입력은 같은 합성 대화에 중립 문맥을 추가해 Granite 기준 3,882토큰, 출력 예산 포함 4,074토큰이 되었다. 해당 Qwen 토큰 길이는 2,934였다. Granite greedy 스트레스 피크는 3.202GB·4.190초, Qwen은 6.766GB·6.648초였다. 이 스트레스 행은 24건 품질 집계에서 제외한다. 75개 생성 모두 production 문자열 인코딩과 사전 토큰화 결과가 같았고, 출력 길이 상한 도달과 명시적 `<think>` 표시는 없었다. 다만 권장 샘플링의 두 사례에는 답장 대신 정책·프롬프트처럼 보이는 설명이 섞였다.

## 해석 및 적용

24건은 기존에 관측한 합성 회귀 사례에 한정된다. 사람의 개인 말투를 실제 대화에서 재현하는지, 학습 후 개선되는지, 실제 회귀 위험을 충분히 포착하는지에 대한 근거는 아니다. 출력 설정이 달라지는 경우 점수는 해당 설정별 관측값으로만 해석한다. 속도와 메모리 차이는 이번 입력·컴퓨터에서 측정한 결과이며, 통계적으로 검증된 모델 우위를 뜻하지 않는다.

운영 적용 결정: **없음. 기존 기본 모델 유지.** 결과는 기존에 본 합성 사례와 단일 위임 검토에 한정되며, 개인화 효과나 실제 대화에서의 모델 우위를 확인하지 못했다.
