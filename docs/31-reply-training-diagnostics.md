# Granite 답장 학습 후 진단과 다음 실험 조건

작성일: 2026-10-06

**1단계 행동 분석과 2단계 기존 실패 분석은 완료했다. 추가 작업으로 3단계의 소규모 진단 자료 15개·4방을 준비했다. 개발 8개·1방, 최종 7개·3방이며 최종의 실질 요청은 2개라 정량 개선 판정에는 부족하다. 실제 추론 준비 완료·새 모델 출력은 0건이며, 새 학습·모델 다운로드·운영 적용은 하지 않았다.**

이번 분석으로 “단순 인사만 대부분 학습해서 답장을 못 한다”는 설명은 수정해야 한다. 인사·감사·확인의 주 행동 비중은 사례의 33.8%, 답장 토큰의 22.0%였다. 거절과 결정·조건 보존의 사례가 적다는 관찰은 남지만, 데이터 구성·숨은 사용자 상태·학습 설정 중 어느 요인이 실제 원인인지는 아직 분리하지 못했다.

원래 설계와 실험 결과는 [27번 설계 문서](27-historical-reply-training-plan.md)와 [30번 학습 문서](30-granite-fullpool-training.md)를 기준으로 한다. 기존 승인·학습·평가 수치와 판정은 바꾸지 않고, 이번 진단과 정정을 별도 증거로 남겼다.

## 1. 실제로 다시 확인한 범위

| 단계 | 실제 수행 | 완료·미완료의 의미 |
|---|---|---|
| 1. 학습 행동 분석 | 학습 1,374건의 원래 문맥과 전체 답장을 새로 의미 판정하고, 반복·민감 원천을 점검 | 전체 답장의 행동 분류 완료. 전체 입력의 요구 행동 분류와 의미상 바꿔 말하기 중복은 미측정 |
| 2. 기존 실패 분석 | 기존 실제 60개·합성 48개 출력과 동결 판정으로 관찰 오류를 재분류 | 108개 전부 포함. 기존 점수를 바꾸거나 원인을 확정한 재평가는 아님 |
| 3. 신선한 평가 준비 | 초기 경로의 자동 알림 4개 이후, 실제 모델 사용 출처를 구분해 추가 전체 문맥·출처·개인정보·기준을 점검 | 추가 소규모 진단 자료 15개·4방 준비, 실질 요청 7개. 최종 실질 요청 2개여서 충분한 최종 품질 평가셋 확보는 미완료. 실제 추론 준비 0개 |
| 4–5. 부족 행동 데이터 보강·소규모 비교 학습 | 실행하지 않음 | 아래 조건과 비교 설계만 제안 |

원래 학습 1,374건의 원문·토큰은 RAM에서 복원해 기존 해시와 대조했다. 원래 봉인 산출물 232개의 파일 해시는 모두 일치했다. 이번에 대화 본문이나 토큰 배열을 디스크에 추가 저장하지 않았다.

행동 판정은 두 위임 에이전트가 각각 687건을 담당했다. 처음에는 기존 세부 범주 805건을 재사용하려 했으나, 표본에서 혼합 행동을 놓치는 문제가 확인되어 이 805건도 모두 새로 읽었다. 최종 장부는 **새 의미 판정 1,374건·기존 범주 상속 0건**이다. 두 검토자가 서로의 표본을 확인하고, 질문과 확인 질문의 경계를 통일한 52개 정정을 원래 판정과 별도로 보존했다. 사람의 전수 검수나 1,374건 전체의 독립 이중 판정으로 표시하지 않는다. 보고서 작성자는 직접 판정에 참여했으며, 독립 검토 범위는 다른 검토자의 표본 21건, 원천·해시·집계, 새 평가 문맥 4건이다.

## 2. 말투 사례와 행동 사례의 실제 분포

혼합 답장의 대표 행동을 한 가지로 정한 집계다. 토큰은 원래 학습의 실제 답장+EOS이며, 토큰 비중이 실제 기울기 가중치와 같다는 뜻은 아니다.

| 주 행동 | 사례 수 | 답장+EOS 토큰 |
|---|---:|---:|
| 인사·감사·확인·사회적 반응 | 464 | 7,327 |
| 의견·조언·도움·격려·공감 | 262 | 9,330 |
| 시간·장소·연락·전달 조율 | 217 | 6,013 |
| 수락·허용 | 145 | 2,825 |
| 일반 질문·요청 | 94 | 2,672 |
| 현재 행동·이해에 필요한 누락 정보 확인 | 93 | 2,770 |
| 정보 제공·답변 | 77 | 1,912 |
| 기존 결정·범위·조건 보존 | 14 | 360 |
| 거절 | 4 | 63 |
| 기타·범주 미확정 | 4 | 28 |
| **합계** | **1,374** | **33,300** |

**717건은 여러 행동을 함께 담았다.** 복수 표지를 세면 인사·확인 813, 의견·도움 387, 조율 366, 수락 219, 일반 질문·요청 167, 정보 제공 129, 누락 정보 확인 110, 결정·조건 보존 76, 거절 5건이다. 이 수들은 겹치므로 합산하면 안 된다. 거절·조건 보존을 주 행동 수 4·14건만으로 전부 설명하는 것도 부정확하다.

확인 질문은 현재 행동이나 이해에 필요한 누락 세부사항이 맥락에서 확인될 때 붙였다. 새 화제를 여는 질문, 일반 행동 요청, 수락 여부를 묻는 협상은 일반 질문·요청으로 남겼다. 현재 상태를 확인하는 사례에도 의료·가족 대화가 포함되므로, 이 110건이 모두 업무 답장에 필요한 확인 행동을 가르친다고 볼 수 없다. 의견·도움도 실질적인 작업 지원 외에 종교적 격려와 정서적 공감을 포함한다.

불확실성·조건 표지는 415건에 있다. 이 가운데 혼합 답장의 대표 행동 선택 표지가 371건, 그 외 자격·불확실성·보이지 않는 자료 관련 표지가 61건이며 두 집합은 겹친다. 415건 전체가 분류 실패라는 뜻은 아니다. 원래 최근 문맥 5개와 전체 답장을 읽고 필요한 경우 앞선 문맥을 더 확인했지만, 보이지 않는 사진·링크 내용을 상상해서 분류하지 않았다.

완전히 같은 답장 문자열은 39개 묶음·121건, 정규화한 같은 답장은 39개 묶음·124건이었다. 각 묶음에서 하나만 남긴다는 가정의 중복분은 각각 82·85건이다. 반면 완전히 같은 학습 에피소드는 0건이었다. 같은 짧은 인사가 서로 다른 맥락에 적절할 수 있으므로 답장 문자열만으로 삭제할 목록은 만들지 않았다. 의미상 동등한 바꿔 말하기의 반복도 측정하지 않았다.

## 3. 민감 원천 검사에서 확인한 정정

추가 숫자 패턴이 학습 70건에 연결된 고유 원천 33개를 표시했다. 33개 모두 맥락을 읽은 결과는 **허용 29·보류 3·제외 1개 원천**이다. 근무시간 숫자, 공개 업체 URL·전화, 일반 통화·업무 배송 연락처를 금융계좌나 접속 비밀로 자동 취급하지 않았다.

제외 1개는 실제 개인 계좌와 개인 예금주를 포함한 송금 안내였다. 기존 개인 금융계좌 제외 부칙이 적용되는 원천이 학습 입력 1건에 들어간 **실제 정책 누락**을 확인했다. 자격증명 중심 패턴 검사의 일치 0건을 모든 민감 범주의 통과로 해석할 수 없었다. 보류 3개 원천은 예약 번호 2개와 예약 조회에 쓰인 휴대폰 번호 1개이며, 접근권한 역할을 더 확인해야 한다.

원천 연결을 적용하면 과거 학습 1,374건 중 향후 제외 1건·보류 4건이다. 나머지 **1,369건·33,199답장 토큰**은 이번 표적 검사에서 차단되지 않았다. 이는 전체 문맥의 개인정보 재승인이나 새 학습 승인·데이터셋 생성이 아니다. 원래 승인 장부와 학습 이력은 보존했고, 실험 가중치는 앞선 사용자 요청에 따라 이미 삭제된 상태다.

## 4. 손실과 유용성의 차이에서 관찰한 것

원래 실험은 Granite 4.2-3B MLX Q4, 마지막 8개 층 LoRA rank 8, 학습률 `2e-5`, batch 1, 한 epoch였다. 기존 관측 valid 30건·844답장 토큰의 손실은 2.75741에서 1.93711로 29.75% 줄었다. 실제 판정 가능 26건에서는 말투가 2.15→3.08, 유용성이 2.31→2.46이었다. 이 수치는 [원래 동결 비교](30-granite-fullpool-training.md)에 그대로 남아 있다.

이번 오류 표지는 기존 판정 사유와 출력에서 관찰한 양상을 묶은 것이다. 서로 겹치며, 정보가 없었다는 조건 자체를 오류로 세지 않았다.

| 기존 출력 묶음 | 모델 | 이미 주어진 정보 누락·충돌 | 누락 정보 처리 실패 | 대화 행동 불일치 | 명확한 의미 실패 |
|---|---|---:|---:|---:|---:|
| 실제 판정 가능 26건 | 기본 | 5 | 7 | 14 | 15 |
| 실제 판정 가능 26건 | 최종 | 3 | 8 | 11 | 11 |
| 실제 모호 4건 | 기본 | 0 | 2 | 2 | 2 |
| 실제 모호 4건 | 최종 | 0 | 4 | 4 | 4 |
| 기존 합성 회귀 24건 | 기본 | 10 | 5 | 15 | 15 |
| 기존 합성 회귀 24건 | 최종 | 9 | 5 | 14 | 14 |

실제 판정 가능 문맥에서는 명확한 의미 실패가 15→11로 줄었지만, 상태를 확인하거나 조건을 붙여야 하는 실패는 7→8이었다. 따라서 말투 개선과 일부 의미 개선을 인정하면서도, 확인·답변·수락·보류 중 적절한 행동을 고르는 문제가 남았다고 보는 것이 맞다. 주어진 정보를 놓친 표지는 attention을 측정한 결과가 아니며, 누락 상태 표지는 수집 시스템의 결함을 증명하지 않는다. **108개 출력 모두 원인 분류는 미확정**으로 남겼다.

실제 30개 입력은 RAM 복원 뒤 원래 입력·프롬프트 토큰 해시에 다시 연결했다. 초기 장부의 원문 미복원 표지는 날짜가 있는 추가 증거로 해소했으며, 새 의미 재평가나 기존 점수 변경으로 표시하지 않았다. 54개 문맥은 이미 검토·출력된 자료여서 신선한 최종 평가로 재사용할 수 없다. 기존 유용성 점수 기반 지표도 새로 판정한 “수정 없이 전송 가능” 비율이 아니다.

## 5. 신선한 평가 문맥을 실제로 확보한 결과

평가 기준은 새 출력 전에 동결했다. 새 방과 같은 방의 나중 시간 구간을 별도 축으로 기록하며, 문맥의 원천·중복·사용자 역할·민감 정보·숨은 정답을 확인한다. 나중 시간 구간은 정답의 시간만 늦으면 되는 것이 아니라 **실제 운영 입력의 전체 원천 창**이 기존 watermark 이후여야 한다. 입력을 잘라 새 자료처럼 만들거나 고정 시간 간격만으로 독립성을 선언하지 않았다.

| 경로 | 실제 조회·구성 | 정식 준비 완료 |
|---|---|---:|
| 새 방의 과거 자기 답장 쌍 | 8방, 자기 메시지 19개·전체 21개에서 적격 과거 답장 후보 0개 | 0 |
| 기존 방의 나중 답장 쌍 | 14범위·원천 10,586행에서 나중 타깃 31개. 전체 문맥이 watermark 이후인 사례 0개, 기존 학습 원천 공유 8개 | 0 |
| 자기 답장이 없는 새 수신 문맥 | 8방의 실제 원문 문맥 8개. preflight ready 6개, 개인정보·사전 조건 통과 4개 | 0 |

수신 문맥에서 금융 거래 문맥 1개는 보류, Slack 2개는 역할·자기 신원 조건으로 차단했고 그중 하나에는 자격증명 접근 링크도 있었다. Telegram 1개는 대화가 아닌 서비스 이벤트라 차단했다. 초기 경로에서 통과한 **4개는 모두 자동 알림**이다. 방 전체를 예약하고 개발 2개·최종 2개로 잠정 배분했으며, 4개 모두 전체 저장 문맥·프롬프트 토큰·해시·타깃 부재를 독립 확인했다.

초기 경로의 이 4개는 정당한 답장 보류를 시험하는 사례이며 **실질 답변 범위는 0개**다. 수정 없이 전송 가능한 답장 비율의 분모에 넣어 성능을 높이지 않는다. 접근 가능한 과거 학습·품질 문맥 1,434개와의 5,736쌍에서는 정확·근접 에피소드 중복과 원천 공유 신호가 없었고, 원래 3,086개 후보의 원천과도 공유가 없었다. 다만 더 넓은 기존 노출 에피소드의 근접 중복 증명과 실제 모델 실행의 입력 결합은 미완료다. 저장된 문맥은 운영 메시지 투영본이며 native 내용 종류와 완전한 답장 연결까지 검증한 자료는 아니다. 초기 경로의 **정식 추론 준비 0개·새 모델 출력 0개·새 독립 품질 시험 0회** 결과는 그대로 보존한다.

이후 답변이 필요한 새 사례에는 모델 출처를 가리고 두 검토자가 각각 전송 가능 여부와 역할·사실·권한·대화 행동을 판정하도록 계약했다. 짝 순서는 반대로 제시하며 판정은 매핑 공개 전에 봉인한다. 오류·차단·불확실 사례를 숨기거나 성공으로 바꾸지 않는다. 작은 방 수의 결과는 진단으로 보고한다. 별도 문서의 전송 가능 80%, 개선 +10%p, 방 단위 신뢰구간·20방 조건 등은 **에이전트가 제안한 연구 성공 정책**이며 사용자 승인 기준이나 운영 적용 권한이 아니다.

### 5.1. 실제 모델 사용 출처로 범위를 구분한 추가 확보

앞선 결과 이후, 사용자의 다음 작업 요청에 따라 추가 수집을 실행했다. 방 목록·사전 준비에만 등장한 자료와 실제 학습·손실 평가·출력 생성에 사용된 자료를 구분하는 평가 규칙을 **새 출력 전에** 동결했다. 주 평가에서는 실제 모델 사용 방을 제외하고, 과거 의미 검토만 있었던 방은 사례별 원천·중복·미해결 출처 검사를 통과해야 한다. 이미 평가한 54개 문맥은 계속 제외한다. 나중 시간의 전체 입력 창이 기존 cutoff 이후인 경우는 별도 엄격 시간 축으로 기록하며, 그 조건을 모든 새 방 사례에 강제하지 않는다.

## 7. 미착수 4–5단계의 실행 조건

4단계인 부족 행동 데이터 보강에서는 답장 말투뿐 아니라 **현재 입력에서 필요한 행동**을 함께 표시한다. 근거가 있는 답변, 수락·거절, 기존 결정 유지, 필요한 확인, 정당한 무응답을 분리하고, 미래 행동 의사와 이미 실행했다는 주장도 구별한다. 실제 계좌 원천 1개는 제외하고 예약 접근정보 보류를 먼저 해결한다. 없는 사용자 일정·선호·결정을 정답에 넣거나 원래 승인 원문을 고쳐 같은 해시로 쓰지 않는다.

5단계인 소규모 비교 학습을 시도한다면, 동일한 기본 모델·답장 예산·입력 규칙에서 데이터 구성 비교와 optimizer 설정 비교를 분리해야 한다. 개발 자료로 설정을 고르고, 최종 자료를 보고 반복 조정하지 않는다. 현재 데이터에서 인사를 일괄 제거하거나 손실 감소만으로 체크포인트를 채택하는 계획은 근거가 부족하다. 실험 모델은 삭제된 상태이므로 실제 학습·모델 재확보는 이번 진단 범위를 넘어가는 별도 실행이다.

3단계에서는 실제 요청 7개를 포함한 15개 진단 입력을 준비했지만, 최종 평가 7개·3방 중 실질 요청이 2개뿐인 범위로는 충분한 최종 품질 평가셋이 아니다. 다음 확보 경로는 **기존 사용 방 안에서도 과거 사용·검토 원천과 겹치지 않는 독립 에피소드**를 찾는 별도 원천 축이다. 이번 추가 작업은 그 경로를 실제로 탐색해 확보한 결과가 아니다. 해당 후보도 원래 전체 입력 창을 유지하고 출처·노출·근접 중복·역할·민감 정보를 확인해야 하며, 알려진 사실·없는 상태·허용 행동·금지 주장을 새 출력 전에 봉인해야 한다. 이를 5단계 비교 학습의 평가 조건으로 사용한다. 실질 답변과 무응답 안전성 결과를 따로 내고, 작은 표본의 변화는 성공 확정 대신 다음 진단 근거로 사용한다. 모델 적용은 학습 완료나 평가 문서 작성으로 자동 승인되지 않는다.
