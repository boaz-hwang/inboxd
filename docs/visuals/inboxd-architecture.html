01

데이터가 지나가는 두 경로

계정 전체 조회와 기존 저장·승인 경로는 함께 존재합니다.

지금의 통합 TUI

메신저에서 직접 가져오기

개인 계정의 전체 채팅방, 메시지, 검색 결과를 메신저에서 조회합니다. 목록과 조회 결과는 메모리에 유지합니다.

TUI→계정 서비스→계정 워커→메신저

account.list · account.messages · account.search · account.send

기존 수집·에이전트 경로

수집한 기록과 승인 이력 다루기

등록된 범위의 메시지를 수집하고 암호화 DB에 저장합니다. 수집 범위, 승인 상태, 전송 이력과 감사 기록도 이 경로에서 관리합니다.

범위별 워커→동기화·공통 규칙→SQLCipher

message.* · sync.* · safety.intent.* · send.status

통합 TUI에서 읽은 모든 메시지가 자동으로 DB에 보관되는 구조는 아닙니다. 서버에서 직접 조회하는 경로와 로컬에 수집·저장하는 경로를 구분해서 이해하면 됩니다.

03

전송 요청의 주체에 따라

누가 보내는지와 전송 결과를 구분합니다.

사용자가 직접

Enter → 즉시 전송

로컬 소유자 인증을 거친 TUI가 정확한 계정·채팅방으로 요청합니다. 승인 코드를 입력하지 않습니다.

작성→전송 중→Sent

전송 중 Enter 중복 입력을 막습니다. 동일 요청 ID의 중복 처리는 현재 데몬이 실행되는 동안 유지합니다.

에이전트가 제안

제안 → 소유자 승인 → 전송

MCP·에이전트는 직접 전송용 account.send를 호출할 수 없습니다. 기존 승인 경로로 제안하고 소유자가 확인합니다.

Proposed→Approved→Sending→Sent

승인·전송 상태는 기존 저장소에 기록합니다. 코드와 소유자 승인 권한은 에이전트에 제공하지 않습니다.

Sent

서비스가 접수함

메신저가 전송을 받아들였습니다. 상대방이 읽었다는 뜻은 아닙니다.

Verified

별도 재조회로 확인함

기존 전송 경로의 독립 조회에서 대상과 내용이 일치했습니다. 직접 전송의 접수만으로 이 상태를 만들지 않습니다.

Uncertain

결과를 확정할 수 없음

응답 유실·시간 초과 등으로 결과가 모호합니다. 중복 발송을 피하기 위해 자동 재전송하지 않습니다.

04

무엇을 어디에 두는가

메모리, 설정 파일, DB, 키체인은 서로 다른 저장 공간입니다.

위치보관하는 내용수명·역할
TUI·데몬 메모리초안, 검색 결과, 채팅 목록 캐시, 직접 전송 중복 방지 정보실행 중에 유지 · 재시작 후 영구 복구를 보장하지 않음
소유자 전용 설정·세션계정 설정, 연결 자격 증명, TDLib 등 서비스 세션다음 실행에서 연결 재사용 · 파일 접근 권한 제한
전체가 SQLCipher 안에 저장되는 것은 아님
SQLCipher기존 경로의 수집 메시지, 검색 색인, 범위·승인·감사 기록암호화된 영구 DB · 데몬의 저장소 액터가 접근 관리
macOS KeychainSQLCipher DB 암호화 키고정된 inboxd-keychain 프로그램이 읽어 전용 파이프로 전달
비밀번호 창이 반복되지 않도록: 키체인 접근 프로그램을 별도 Rust 실행 파일로 분리했습니다. 일반 실행에서는 인증 창을 띄우지 않고 저장된 권한을 사용합니다. 최초 권한 등록, 키체인 잠금, 접근 권한 변경은 별도 처리가 필요합니다.

06

확장 방향과 현재의 경계

확장 지점

새 메신저 추가

연결 드라이버와 계정 어댑터를 구현하고 데몬 설정·워커 등록을 추가합니다. 공통 요청과 메시지 형식을 따르며, UI에는 표시 이름·색상 등을 연결합니다.

현재 제한

실시간 전체 계정 구독

아직 구현하지 않았습니다. 시작 시 또는 b로 목록을 갱신합니다. 통합 첫 화면은 대화별 최신 메시지이며, 모든 과거 메시지를 한꺼번에 펼치는 화면은 아닙니다.

현재 제한

과거 기록과 검색 범위

메신저가 제공하는 기록 범위에 따릅니다. 검색은 계정별 최대 25페이지를 자동으로 잇고, 남은 결과는 n으로 이어 봅니다. TUI 제어 로직의 추가 분리도 개선 지점입니다.

현재 구현을 설명하는 독립형 HTML · 외부 라이브러리·네트워크 요청 없음근거: 연결 설계 · 계정 설계 · 저장·키체인 설계
